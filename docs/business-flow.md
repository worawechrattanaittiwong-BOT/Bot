# Business Flow แบบภาษาคน

## ลูกค้าใหม่
1. เข้าเว็บและสมัคร
2. ได้ User ID เช่น BOT-ABC123
3. เชื่อมบัญชี Exness MT5
4. เลือก Cloud หรือ Local
5. ถ้าต้องการทดลองใช้ฟรี ทักผู้ดูแลพร้อม User ID
6. ผู้ดูแลค้นหา User แล้วกด + Trial 3h
7. ลูกค้ากด Start ครั้งแรก → เริ่มนับ 3 ชั่วโมง
8. ปิดเว็บหรือมือถือได้

## หลัง Trial
- ครบเวลาแล้วระบบไม่เปิดรอบใหม่
- Basket ที่มีอยู่ถูกจัดการโดย Safe Stop
- ลูกค้าชำระเงินแล้วแจ้ง User ID
- Admin เลือกแพ็กเกจ + จำนวนวัน แล้ว Activate
- ลูกค้ากด Start ใช้งานต่อได้ทันที

## Cloud customer
ไม่ต้องมีคอม. Trading VPS ของระบบต้อง online 24/7.

## Local customer
ต้องเปิดคอม + MT5 + Algo Trading. เว็บสามารถปิดได้.

## ลูกค้าดูออเดอร์
ลูกค้าล็อกอิน MT5 บัญชีเดียวกันจากมือถือ/คอมของตัวเอง จะเห็น Position และ History ที่บอททำบน broker account เดียวกัน.
